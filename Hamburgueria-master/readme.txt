# 🍔 Hamburgueria App – Sistema Web e Mobile

## Descrição
Aplicativo completo para uma hamburgueria, permitindo que clientes façam pedidos presencial ou delivery, garçom gerencie pedidos e administrador controle estoque, vendas e funcionários pelo sistema web.  

O projeto integra **Mobile (Flet)**, **Web** e **API**, simulando um sistema real de gestão de pedidos e negócios.

---

## Funcionalidades

- Cadastro e login de usuários (Cliente, Garçom)  
- Pedido de lanches para delivery ou presencial  
- Modificação de insumos nos lanches (adicionar/remover)
- Interface para o garçom, fazendo ele realizar o pedido do usuário presencial, fechamento da mesa


---

## Tecnologias Utilizadas

- Linguagens: Python(Framework Flet)
- Framework: Flet (Mobile/Interface)  
- Controle de versão: Git e GitHub  
- API REST para comunicação entre sistemas
