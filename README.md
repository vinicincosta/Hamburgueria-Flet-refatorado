## 📌 Sobre o projeto

Este projeto começou como um trabalho em grupo durante meus estudos no **SENAI** e evoluiu ao longo do tempo para um **ecossistema completo de gerenciamento de hamburgueria**.

Ele integra diferentes aplicações para controle operacional, vendas e gestão de estoque em um único sistema.

---

## 🧩 Arquitetura do sistema

O sistema é composto por três módulos principais:

| Módulo | Descrição |
|--------|----------|
| 📱 App Cliente (Flet) | Realiza pedidos, personalização de lanches e acompanhamento |
| 🍽️ App Garçom | Atendimento presencial e gestão de pedidos |
| 💻 Sistema Web | Painel administrativo completo |

## 🔧 Funcionalidades

### 📌 CRUD completo
- Categorias  
- Lanches  
- Bebidas  
- Insumos  
- Pessoas  
- Lanches × Insumos  
- Vendas  
- Pedidos  
- Entradas de estoque  

---

### 📦 Controle de estoque inteligente
- Entrada de insumos com registro detalhado  
- Controle de quantidade e valores  
- Associação com notas fiscais  
- Atualização automática de disponibilidade  

---

### 🍔 Sistema Lanche × Insumo
Cada lanche é vinculado aos seus ingredientes, permitindo:

- Baixa automática de estoque  
- Controle de receitas  
- Gestão de custos operacionais  
- Reajuste automático de disponibilidade  

---

### 📝 Personalização de pedidos
O cliente pode personalizar pedidos no app:

- Remover ingredientes  
- Adicionar ingredientes  
- Ajustar quantidades  

Essas alterações impactam diretamente o estoque em tempo real.
